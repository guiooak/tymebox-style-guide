# Tymebox style guide

The Tymebox logo manual and style guide, published at
**https://guiooak.github.io/tymebox-style-guide/**.

The manual lives in the app's repository, at
[`docs/brand/tymebox-brand-manual.html`](https://github.com/guiooak/tymebox/blob/main/docs/brand/tymebox-brand-manual.html):
edit it there. This repository only publishes it. Its workflow fetches the
current version and deploys it to GitHub Pages every day, and on demand
(Actions → Publish → Run workflow).

The app itself is at https://tymebox.web.app.
